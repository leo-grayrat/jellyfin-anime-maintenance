# 对话交接入口

如果需要由新的 ChatGPT / AI 对话继续维护本仓库，请**不要只读取一份技术摘要就开始写代码**。

至少先读下面两份文档：

1. [`2026-08-14-next-conversation.md`](./2026-08-14-next-conversation.md)
   - 当前仓库、issue、PR、脚本、数据基线和下一步操作；
   - 回答“现在在哪里、接下来具体做什么”。

2. [`2026-08-14-project-story.md`](./2026-08-14-project-story.md)
   - 为什么最初会建立这个仓库；
   - 用户真正想保留的动画收藏方式；
   - NFO、LocalAlternateVersion、canonical view、统一 audit 等方向为什么一步步出现；
   - 哪些判断被实验推翻；
   - 协作过程中为什么逐渐形成 issue-first、真实环境验证、不要忘旧问题、不要把局部成功扩大成全局结论等规则；
   - 回答“为什么项目会走到今天、哪些弯路不要重走”。

两份文档缺一不可。

这个项目的目标不是单纯“让脚本跑通”，而是在**尽量不破坏用户原始动画收藏方式**的前提下，让 Jellyfin 能长期、稳定、可维护地正确理解这套收藏。
