Later source review changed the interpretation:
- POST /Library/Media/Updated calls ReportFileSystemChanged(path).
- FileRefresher resolves an existing BaseItem and calls ChangedExternally().
- ChangedExternally() queues a metadata refresh on that existing item.
- Therefore this endpoint is not equivalent to a structural library rescan.

The failed experiment invalidated the earlier assumption that reporting the directory as Modified would force creation of a missing Season object.
